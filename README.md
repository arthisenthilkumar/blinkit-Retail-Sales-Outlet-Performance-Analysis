# blinkit-Retail-Sales-Outlet-Performance-Analysis

## 📊 Project Overview
This data analytics project evaluates retail sales performance, outlet efficiency, and customer satisfaction metrics for Blinkit grocery deliveries. The goal is to uncover optimization opportunities for inventory distribution, identify high-performing outlet types, and improve overall customer ratings.

## 🖼️ Executive Dashboard
![blinkit Sales Dashboard](Screenshot%202026-09-01%20124755.png)

## 📈 Key Retail Metrics Discovered
- Total Revenue: $1.20M generated across all grocery segments and retail outlets.
- Average Ticket Size: $141 mean order value per customer checkout transaction.
- Inventory Volume: 8,523 items successfully cataloged and tracked in the fulfillment pipeline.
- Customer Satisfaction: An average rating of 3.9 / 5.0, showing key opportunities for service and quality improvements.

## 🛠️ Tools & Technologies Used
- Data Source: Blinkit Grocery Dataset from Kaggle
- Data Analysis & Dashboard Design: Microsoft Power BI, used power query for cleaning and transforming the dataset.
